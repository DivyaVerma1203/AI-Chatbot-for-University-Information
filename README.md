## Overview
Developed an AI-driven university assistant using Python and NLP to deliver instant answers from structured institutional data. Utilized TF-IDF vectorization and cosine similarity for precise semantic query matching and efficient context retrieval. Built and deployed a scalable web interface with version control on GitHub to enable real-time, multi-user interactions.
